# GTA VI — Projeto Bibliotecas JavaScript

Site escolar independente sobre GTA VI. A página usa três bibliotecas JavaScript com funções diferentes:

| Biblioteca | Uso na página | Código principal |
| --- | --- | --- |
| Swiper 11.2.10 | Carrossel de imagens oficiais de divulgação | `new Swiper('.gallery', {...})` |
| AOS 2.3.4 | Animação das seções na rolagem | `data-aos="fade-up"` e `AOS.init()` |
| canvas-confetti 1.9.3 | Partículas no clique do botão | `confetti({...})` |

Abra `index.html` em um navegador conectado à internet. As bibliotecas e as fontes de texto são carregadas por CDN. Para apresentar: role a página (AOS), navegue pela galeria (Swiper) e clique em “Soltar confetes” (canvas-confetti).
